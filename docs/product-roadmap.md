# 곁에: 시연·제출 지원서 기반 개발 순서

2026-09-21. 기능 순서는 최종 제출 지원서의 개인화·공동 이용·실제 행동 지원을 우선한다.

## 근거 자료

- `지원서_권지윤.pdf` (2026-09-16 제출 미리보기), Q3-1 및 MVP 개발 범위
- `곁에_v0.27_핵심우선_음량개선_59초_1080x1920.mp4` 주요 장면: 가족별 화면, 내 설정, TV/리모컨 사진, 키오스크 단계, 가족 도움 요청
- `곁에_공유생활AI_사업기획서.pdf`의 원본 자료·변경 이력·확인 관리 구조는 공동 정보 기능의 근거로 사용
- 구버전 수정지시서와 최종 지원서가 다르면 제출 지원서를 우선한다. 개인정보가 포함된 원문과 영상은 이 저장소에 넣지 않는다.

## 선행 작업: Google 계정

구현·배포: 기존 개인방에 Google 연결, 새 기기에서 동일 계정 복구, 현재/모든 기기 로그아웃.
남은 작업: Google 웹 OAuth 클라이언트 등록, Worker secrets 설정, 실제 로그인 및 휴대폰 설치 앱 복귀 검증.
콜백: `https://app.tridatum.co/api/auth/google/callback`.
설정 완료 전에는 기존 접속 코드 이용을 유지한다.

## 1. 가족 그룹방 + 도움 요청 (첫 기능 묶음)

사용 흐름: 가족방 생성 → 초대받은 각자 계정으로 가입 → 개인 도움 중 막힘 → 공유할 내용/사진/받는 방 확인 → 가족방에 도움 카드 → 가족 답변 → 요청자가 해결 완료.

- 개인방과 그룹방을 명확히 구분한다. 그룹 초대는 개인방 계정에 연결하는 기존 기기 연결 코드와 다르다.
- 초대는 만료·취소가 가능한 별도 토큰으로 관리한다. 방장·구성원 권한을 서버에서 확인한다.
- 개인 질문과 사진은 자동 공유하지 않는다. 공유 전 미리보기와 방 선택을 제공한다.
- 도움 요청에는 막힌 단계, 사용자가 고른 설명과 사진만 포함한다. 전체 개인 대화를 공개하지 않는다.
- 읽음, 확인했어요, 단계 완료, 도움 해결은 각각 다른 상태로 저장한다.
- 가족은 자신의 이름으로 답변한다. 미리보기는 읽기 전용이고 타인의 상태를 변경하지 않는다.

완료 기준: 서로 다른 세 계정에서 초대·공유·답변·해결이 동기화된다. 비구성원은 메시지/사진에 접근할 수 없다. 가족방에 가입해도 상대 개인방에 접근할 수 없다. 재전송으로 도움 카드가 중복 생성되지 않는다.

## 2. 개인별 화면·설명·접근성

- 큰 글씨, 정보량, 한 단계씩/핵심만/자세히, 음성 재생 속도를 사용자가 직접 고른다.
- 나이·가족 역할로 고정하지 않는다. 설정 대상은 본인임을 명시한다.
- 공동 정보의 날짜·시간·장소·확정 여부는 하나의 공통 데이터에서 표시한다.
- 쉽게 모드는 행동 결론부터, 단계 모드는 목적과 지금 할 일 하나부터, 자세히 모드는 근거와 선택지를 표시한다.

완료 기준: 동일 공유 항목을 각자의 설정으로 봐도 핵심 사실이 일치한다. 본인의 설정 변경이 다른 가족의 설정을 변경하지 않는다.

## 3. 사진으로 지금 할 일 안내

- 사진 → 관찰한 대상 확인 → 첫 행동 → 다음 사진/완료 응답으로 다음 단계.
- TV·리모컨·키오스크 등 과제를 구분하고 검증된 안내와 사진의 근거를 연결한다.
- 버튼 위치 강조는 실제 사진의 위치 근거가 확인된 경우에만 제공한다.
- 알아보기 어렵거나 상태가 불확실하면 가까이 찍기/추가 질문으로 전환한다.
- 실패하거나 막히면 1번의 가족 도움 요청으로 바로 연결한다.

완료 기준: 다른 화면·모델의 사진을 넣었을 때 고정 좌표나 미리 정한 정답을 보여주지 않는다. 결제·주문 확정 등은 사용자가 직접 확인한다. 단계 성공률·중단 지점을 평가한다.

## 4. 음성 질문 + 답변 듣기

- 녹음 시작·중지·취소와 인식 문장 수정 후 보내기를 제공한다.
- iOS/Android 지원 범위를 실기기로 검증하고, 미지원 시 문자·사진 입력을 안내한다.
- 기존 음성 읽기에 속도·정지·다시 듣기 설정을 더한다.

완료 기준: 녹음 종료와 취소가 확실하며, 잘못 인식된 문장을 사용자가 고칠 수 있다. 녹음을 자동으로 가족에게 공유하지 않는다.

## 5. 공유 자료 → 일정·할 일 → 변경 반영

- 승차권/문자에서 추출한 항목을 원문과 함께 확인 후 저장한다.
- 시간 계산은 규칙 코드로 처리한다. AI는 사실 추출과 설명을 담당한다.
- 원본 변경 시 영향받는 일정 수정안을 보여주고 승인 후 적용한다.
- 이전/현재 값과 변경자를 남기고 새 버전에 대한 확인 상태를 따로 관리한다.
- 담당자 수락, 읽음, 완료를 분리하고 완료한 일을 재생성하지 않는다.

완료 기준: 출발 시각 변경이 연결된 모임 시각에만 반영되고 준비물 완료 상태는 유지된다. 새 자료가 같은 예약인지 불확실하면 먼저 확인한다.

## 첫 시연 성공 기준

부모가 사진으로 도움을 받다가 막힌 지점을 가족방에 공유하고, 자녀가 답변하면 부모가 자신의 화면에서 다음 행동을 수행해 해결 완료한다. 서로 다른 실제 계정과 기기에서 이 흐름을 끝까지 확인한다.
