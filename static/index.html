나에게 맞게

새로 받는 답변에 적용돼요.

대화는 곁에 서버에 저장돼요. 보낸 글과 사진, 최근 대화 일부를 Claude에 전달해 답변을 받아요. 최근 8개 문답을 참고하며, 이전 사진의 원본은 다시 전달하지 않아요.

나눈 이야기

대화 이어보기

다른 휴대폰이나 컴퓨터에서도 같은 대화를 볼 수 있어요.

다른 기기에서 곁에를 열고 아래에 코드를 입력해 주세요. 코드는 10분 동안 한 번 쓸 수 있어요.

연결하면 코드를 만든 기기의 대화로 전환돼요. 이 기기의 기존 대화가 합쳐지지는 않아요.

곁에를 홈 화면에

아이폰 · Safari

공유 버튼 → 홈 화면에 추가 → 추가

안드로이드 · Chrome

메뉴(⋮) → 앱 설치 또는 홈 화면에 추가

인터넷에 연결되어 있어야 새 답변을 받을 수 있어요. 이 버전은 스토어 배포 전의 개인 테스트 앱이에요.
